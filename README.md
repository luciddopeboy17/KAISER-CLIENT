# KAISER CLIENT

KAISER CLIENT is a personal Minecraft Java Edition client development project based on the open-source LiquidBounce Nextgen project.

## Project Overview

The project focuses on client customization, interface development, and integration with legitimate Minecraft Java Edition accounts.

## Microsoft Authentication

KAISER CLIENT uses Microsoft device-code authentication and Xbox Live/XSTS services to authenticate users.

The application is designed to verify Minecraft Java Edition ownership before providing authenticated gameplay access.

Minecraft Services authentication is currently pending application review.

## Development Status

- Original LiquidBounce client successfully compiled and launched.
- Microsoft device-code authorization implemented and tested.
- Xbox Live/XSTS authentication tested.
- Minecraft Services authentication awaiting successful authorization.
- Project remains in private development.

## Distribution

KAISER CLIENT is currently intended for personal development and testing and is not publicly distributed.
